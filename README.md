# 🧠 AI Mood Detector using NLP and Machine Learning

## 📖 Project Description

The AI Mood Detector is a Machine Learning and Natural Language Processing (NLP) based web application that predicts a user's mood from text input. The system analyzes the entered sentence, preprocesses the text using NLP techniques, and classifies it into emotions such as Happy, Sad, Angry, Fear, Love, and Surprise. The application is built with Python and deployed using Streamlit, providing a simple and interactive user interface for real-time mood prediction.

---

## ✨ Features

- Predicts emotions from text input
- Uses Natural Language Processing (NLP)
- Real-time mood prediction
- Interactive Streamlit web interface
- Supports multiple emotion categories
- Fast and user-friendly application
- Machine Learning-based text classification

```bash

```

### Move to the project folder

```bash
cd AI-Mood-Detector
```

### Install dependencies

```bash

```

### Run the application

```bash
streamlit run app.py
```
